# Ficha de Ponto BERG (app offline)

App da **Ficha de Descrição de Ponto v0.5** da BERG Serviços Geológicos.
Funciona 100% offline depois da primeira abertura. As fichas ficam salvas **somente no celular** de cada geólogo
(nenhum dado é enviado para este repositório).

- Abrir/instalar: link do GitHub Pages deste repositório → Chrome → ⋮ → "Instalar app".
- Exportar: botão "Exportar fichas" gera um .zip (Excel + croquis + backup) para enviar por WhatsApp/e-mail/Drive.
- Consolidar: "Mais" → "Consolidar arquivos da equipe".

Regra de ouro: **exporte as fichas todo dia**. Limpar os dados do Chrome apaga fichas não exportadas.
